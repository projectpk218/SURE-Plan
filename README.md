# SURE-Plan Full Application

Full A–Z MBA project application:
1. Login
2. Project context
3. Order intake
4. AI/ML delivery-risk prediction
5. Dynamic resource allocation
6. Daily schedule
7. What-if disruption testing
8. Final solution/recommendation centre
9. CSV/TXT exports
10. Admin model/resource controls

Prototype ML hold-out accuracy on simulated data: 99.9%

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Public deployment
Use Streamlit Community Cloud with a GitHub repository.
Set passwords in Streamlit Secrets using `.streamlit/secrets.toml.example`.
